# Study: media in the composition

Open when proof is about to become a gray rectangle, a stock gradient, or a
long text list because "we have no screenshot."

If the brief already has photographs or generated stills, open
[media-portfolio.md](../examples/media-portfolio.md) instead — this study is
the missing-media case.

Two honest options on one fragment: a labeled interface diagram derived
from the product, composed as the stage — not a fake capture.

## Brief

Tideprint is a small CLI that prints tide tables for a named berth.

Real content already in the copy:

- Command: `tideprint --berth A3 --hours 12`
- Sample rows: 06:12 flood, 12:48 slack, 18:05 ebb (demo table)
- Action: copy the install line `npm i -g tideprint` (fictional package)

No product photography exists. Do not invent a laptop mockup photo.

## What to do

Put the tool in the first viewport as an **SVG terminal** whose rows match
the demo data. Caption it: "Interface diagram, not a screenshot." On a
narrow screen, type first, then a tighter crop of the same diagram
(`overflow` + keep the command line visible).

Phosphor-on-harbor is a *this product* choice (night ops, terminal). Do not
reuse it on Kiln Rest or Sona Hale.

[media-in-composition.html](media-in-composition.html)

## What not to do

- Empty `min-height` box
- Unlabeled generated picture of a terminal
- Turning the page into a numbered essay because media was missing
- Copying Linear's issue-tracker chrome (different object)

## Takeaway

Missing photography is a brief, not a dead end. Diagrams and type can be
the proof if you say what they are.
