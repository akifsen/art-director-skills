# Study: intentional minimalism vs unfinished

Open when a sparse page might be taste — or might just be default HTML.

Same facts. One file is a complete quiet composition. The other is an
empty starter. Whitespace is not the difference; decisions are.

## Brief (shared)

Sona Hale translates patents. One service, one language pair on this
fragment, one email.

- Name: Sona Hale
- Work: EN ↔ TR patent claims, including `ğüşıöç`
- Action: `sona@hale.example`
- No testimonials, no client logos, no "years of experience" metric

## Quiet (finished)

A paper field, a hairline, a name with a real measure, a single sentence,
an email with hover and `:focus-visible`. Empty space frames the name. The
Turkish letters must render in the chosen stack.

[minimal-vs-unfinished.quiet.html](minimal-vs-unfinished.quiet.html)

## Unfinished

Browser-like defaults, a gray hero box, "Welcome," "Coming soon," an
unstyled list, no focus style, Arial. The facts are present; the page is
not directed.

[minimal-vs-unfinished.unfinished.html](minimal-vs-unfinished.unfinished.html)

## How to tell them apart

| | Quiet | Unfinished |
|---|---|---|
| Measure | Name and sentence share a column | Width is whatever the window is |
| Type | One humanist sans, one size step | Accidental sizes, mixed alignment |
| Action | The email *is* the button | "Get started" or raw blue link |
| Space | Gutter that matches the hairline | Leftover margin |
| States | Focus ring designed | Browser default or none |

Minimalism that is finished still has a thesis: "the name and the mail are
the whole product." Unfinished work has no thesis, only missing parts.
