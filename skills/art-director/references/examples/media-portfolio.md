# Example — media-led catalog (Rail Still)

**When:** the proof is visual work the visitor must see first (catalog,
portfolio, product stills). **Not:** a job tracker, a cream ledger, or a
look to paste onto an ops tool.

Copy the *method*: the still sets the opening geometry; type is a caption
with a job; the next band changes density. Do not copy the cool-gray canvas,
copper rule, or these generated stills onto another product.

## Run (this repository, maintainer)

After `npm ci`:

```sh
npm run example:rail
```

Open `http://127.0.0.1:5176/`. Vite compiles this folder.

```sh
npm run test:examples:build
```

## What this is teaching

| Decision | This catalog's voice | Quality on any product |
|---|---|---|
| First look | Fixture still as the stage | The proof of the job is first |
| Type | Grotesque display, sentence-case nav | Roles exist; faces load; hierarchy reads |
| Surface | Cool stone, unrounded photos, copper tick | Named roles and contrast — not leftover white + `#ddd` + purple |
| Media | These generated stills, captioned as demo | Honest material, cropped for the object |
| Next band | Uneven yard / arm crops | Density changes; not three equal cards |
| Action | Sharp filled mail control | Label readable on the fill; focus visible; purpose clear |

Do not paste this cool-gray sharp catalog onto a job tracker. Narrow: type
stacks above the crop; the hero shortens; work stacks. Keep the inquire
label readable after any link reset.
