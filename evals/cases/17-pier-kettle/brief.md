# Brief — Pier Kettle

A tiny web board for a harbor tea stall. Staff start a three-minute steep
for a cup they just poured, then mark it ready.

Real cups (do not invent customers, wait times, or a shopper app):

- K-12 · glass mug · oolong
- K-19 · enamel cup · black

Primary task: see which cup is steeping, start a steep, mark it ready, and
undo if the wrong cup was started.

Mode: DESIGN. Platform: web. Foundation: starter / no system.

Keep this in the browser session. Label the demo. Use the supplied cups.
No accounts, payments, menus, or backend.

This is not Fold, Daypack, Lumen Cart, Kiln Queue, or a packing list.
