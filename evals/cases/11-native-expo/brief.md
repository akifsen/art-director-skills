# Brief — Railbag (native)

Design a **React Native / Expo** app for a small-station lost-and-found.

Real items (do not invent owners or serial numbers):

- R-14 · Navy umbrella · platform 2 · open
- R-09 · Child’s red glove · waiting room · open
- R-03 · Paperback, Turkish · ticket hall · claimed

Mode: **DESIGN**. Platform: **native mobile**. Foundation: **starter**.

Required:

1. List of items
2. Detail
3. Edit note (required text) with keyboard avoiding the save action
4. Safe area insets; a sheet or modal after save
5. Empty or error state that belongs to this flow
6. Native accessibility labels/roles/states — not ARIA copies

Keep system fonts unless you load a real face. Do not add new permissions
or haptics. Do not wrap HTML in a phone frame. Expo web is not iOS/Android
verification.

This is not a website mobile menu.
